# 新車銷售獎金計算機

Honda 新車銷售點數級距獎金試算工具。單一頁面、離線可用、資料只存在使用者自己的裝置。

## 規則
| 累計點數 | 每點獎金 |
|---|---|
| 0–4 點 | $0 |
| 5–7 點 | $2,500 |
| 8–10 點 | $4,500 |
| 11 點以上 | $6,500 |

跨過門檻時前面所有點數一併重算（4→5 點為 12,500；7→8 點一次多 18,500）。
點數：CR-V／HR-V／FIT 油電 2 點；CR-V／HR-V／FIT 汽油、CIVIC、ZR-V 1 點。

## 檔案
- `index.html` 主程式（含版面與邏輯）
- `manifest.webmanifest` / `sw.js` / `icon-*.png` 加到手機主畫面與離線快取
